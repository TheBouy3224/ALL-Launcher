# ALL Launcher 1.1.0 — source package (arm64-v8a)

> **ALL Launcher is an Unofficial Modified Version of Zalith Launcher 2.** It is not made, endorsed or supported by the Zalith Launcher developers.
>
> **Release Candidate 3.** Microsoft sign-in uses the inherited public Minecraft launcher client ID (`00000000402b5328`, legacy Live device-code endpoint) exactly as ALL 1.0.0 and Zalith Launcher 2; ALL has no Microsoft app of its own and Microsoft/Mojang have not approved ALL (`PUBLIC-RELEASE-REQUIREMENTS.md`). Some small components have no public source yet (`THIRD-PARTY-SOURCES.md`).

## 1. What this is

- Source of ALL Launcher 1.1.0 RC3 (applicationId `com.all.launcher.app`, versionCode 22, versionName 1.1.0).
- Input of the arm64-v8a release APK `ALLLauncher-1.1.0-RC3-arm64-v8a.apk`, SHA-256 `72ddc2939b0d4cd6b7b80c8188de64729b7ea53f57077113f76a2272f06f190d`, signed with the ALL release key (certificate SHA-256 `b72b76bd56f32ae16a3c10bac9fad1bd68a8d48ada273fcf4530f854089d2177`, same as 1.0.0).
- Licence: GNU GPL-3.0 (`LICENSE`). Upstream: Zalith Launcher 2 by MovTery and contributors (GPL-3.0 with additional terms), which builds on PojavLauncher and other open-source projects (`NOTICE.md`, About page).
- Two files accompany the APK: this zip and `ALLLauncher-1.0.0-OPENJDK-SOURCES.zip` (the four OpenJDK trees behind the bundled Java runtimes; the runtime archives, components and licence files in the 1.1.0 APK are byte-identical to 1.0.0, so the same OpenJDK zip applies). `BUILD_SOURCE_SHA256_1.1.0.txt` lists every file hash; `CHANGED_vs_1.0.0.txt` lists changes against the 1.0.0 source package.

## 2. What ALL changed since 1.0.0 (ALL's own code, GPL-3.0)

- `ZalithLauncher/src/main/java/com/movtery/zalithlauncher/all/bouy/`: BOUY touch controls and Control Studio (replaces the old control editor: `ui/activities/ControlEditorActivity.kt`, `ui/screens/main/control_editor/`, `viewmodel/EditorViewModel.kt`, `all/controls/` are removed).
- `.../all/fg/` and `ZalithLauncher/src/main/jni/framegen/`: Frame Generation (experimental, off by default; one hook in `ctxbridges/gl_bridge.c`).
- `.../all/unlockfps/`: Unlock FPS. `.../all/music/` and `all/game/AllGameMusicPage.kt`: Music Player V1 (files on the device only). Chat input above the keyboard: `ui/activities/VMActivity.kt`.
- Assets: `assets/all_bouy_a`, `assets/all_bouy_b` (control artwork generated by ALL from Tabler Icons, MIT), `assets/fonts/NotoSansThai.ttf` with its licence `OFL-NotoSansThai.txt` (SIL Open Font License 1.1, Noto Project Authors).
- RC2 over RC1: Quick Menu shows Frame Generation "Off" when the saved mode is Off (`all/game/AllGameMenu.kt`); Vulkan check wording in English and Thai (`res/values*/strings.xml`).
- RC3 over RC2: Microsoft sign-in note text (en, th), the Gradle `ALL_PUBLIC_RELEASE` guard accepts the empty (public client) id, Tabler Icons MIT and Noto OFL licence files added under `assets/licenses`. Artwork skins A/B: generated by ALL from Tabler Icons (see THIRD-PARTY-SOURCES.md).

## 3. Upstream terms (Zalith Launcher 2, additional terms under GPLv3 section 7)

- The program name must not contain "ZalithLauncher" or "ZL": the name is "ALL Launcher" (`launcher_name=ALLLauncher` in `ZalithLauncher/gradle.properties`).
- Modified versions must say "Unofficial Modified Version" on the startup screen or main interface: done on the sign-in (startup) screen, in the start menu footer and in About.
- Copyright notices must stay: About shows "© 2025 MovTery and contributors · GNU GPL v3"; source headers are kept.

## 4. Build

- Gradle 9.5.0 (wrapper), Kotlin 2.4.10 (`gradle/libs.versions.toml`), Android NDK 25.2.9519653 (`ZalithLauncher/build.gradle.kts`), JDK 25.
- Command: `./gradlew :ZalithLauncher:assembleRelease -Darch=arm64` (RC3 build log: lint ran, no check disabled, `ALL_PUBLIC_RELEASE=1` set, `OAUTH_CLIENT_ID` empty).
- A public build uses `ALL_PUBLIC_RELEASE=1`. `OAUTH_CLIENT_ID` stays empty (public client path); if set it must be a GUID of the builder's own Azure app (which Microsoft must approve for the Minecraft API).
- Needed but **not included**: `local.properties` (`sdk.dir`); the release keystore `../private-signing/all_launcher_release.jks` (alias `all_launcher`) and its passwords (env `ALL_STORE_PASSWORD`/`ALL_KEY_PASSWORD` or `private-signing/all_launcher_release_password.txt`). Without them the release build cannot be signed with the ALL key; anyone rebuilding gets a differently signed APK. Optional, not included: `.oauth_client_id.txt`, `.curseforge_api.txt`.
- `ZalithLauncher/libs/MobileGlues-release.aar` holds the arm64 `libmobileglues.so` built from `third_party/mobileglues/` (recipe: `third_party/mobileglues/BUILD-RECIPE.md`).
- The other prebuilt native libraries and runtimes in the tree come from Zalith Launcher 2 and are not modified by ALL; their upstream sources are listed in `THIRD-PARTY-SOURCES.md`.

## 5. Not included, by policy

Signing keys and passwords, OAuth ids, tokens, account data, `local.properties`, Gradle and Kotlin caches, build outputs, test profiles, screenshots, Minecraft worlds.
